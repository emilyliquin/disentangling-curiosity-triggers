Experiment code for Study 2b, "A computational approach to disentangling the triggers of curiosity in children and adults" (Liquin et al., submitted).

To preview the study locally, set up a local HTTP server in this directory. For example, with Python 3:

```
python -m http.server 8000
```

Proceed to http://localhost:8000/?cond=1.

Set the "cond" variable in the URL to view different conditions:
_Intervening Agent_: Bandit (conds 1), sheriff (conds 2), tycoon (conds 3).

In this study, all participants rated "global learning potential" on each trial, rather than curiosity.
